# テストの規約

## 役割分担

- 単体テスト: Vitest。中核ロジックを最も厚くテストする
  - 要素 ↔ ソース位置の対応付け
  - 編集の適用
  - コメントの紐付け
  - IndexedDB への保存と復元
- E2Eテスト: Playwright。Chromium のみで実行する

## E2Eで必ず用意するシナリオ

- iframe 内の要素をクリックすると、レイヤーツリーの該当ノードが選択される
- CSS を編集すると、プレビューに反映される
- JS を編集して iframe を作り直しても、HTML/CSS の編集が残る
- ブラウザを再読み込みしても、編集とコメントが残る
- Service Worker の初回登録時でも、プレビューが正しく表示される

## 書き方

- iframe 内の要素は `frameLocator` で取得する
- テスト用サンプルサイトとして、次の種類を用意して使う
  - 1ページ＋画像
  - JS（スライダーなど）入り
  - 閉じタグ漏れなどの不正な HTML 入り
- テスト用サンプルサイトは期待値の基準なので、テストを通すために書き換えない
