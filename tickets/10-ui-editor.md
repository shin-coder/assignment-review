# 10: UI コードエディタ

- Wave: 1
- 依存: 00
- 担当ディレクトリ: `src/ui/editor/`
- 変更禁止の領域: `src/shared/`, `package.json`, ルートの設定ファイル, 他層のディレクトリ

## 目的

HTML / CSS / JS をその場で編集できるコードエディタを CodeMirror 6 で作る。編集内容を親アプリに渡すだけにし、ソース管理層とはつながない。

## 関連する設計ルール

- UI層（React）: レイヤーツリー、コードエディタ、コメント一覧
- HTML/CSS の編集は iframe の DOM を直接書き換えて終わりにせず、編集後のソース（テキスト）に反映する（このコンポーネントは編集後のテキストを親に渡す役）

## 実装チェックリスト

- [ ] `FileTabs` コンポーネント: 開いているファイルの切り替え。編集済みのファイルに目印を付ける
- [ ] `CodeEditor` コンポーネント
  - [ ] props: `path`, `value`, `onChange(text)`, `highlight: SourceLocation | null`, `onCursorChange(offset)`, `readOnly?`
  - [ ] 拡張子で言語（HTML / CSS / JS）を切り替える
  - [ ] `value` が外から変わったとき、カーソル位置とスクロールをできるだけ保つ（自分の `onChange` による更新で無限ループしない）
  - [ ] `highlight` が渡されたらその範囲を強調表示し、見える位置までスクロールする（レイヤーツリーや iframe で要素を選んだときの連動）
  - [ ] `onChange` は入力のたびではなく短い間隔でまとめて呼ぶ（間隔は定数）。JS ファイルは「適用」ボタンまたはショートカットで確定してから呼ぶ（iframe の作り直しが頻発しないように）
  - [ ] 画像などバイナリファイルはエディタで開かず、プレビュー表示か「編集できません」表示にする
  - [ ] 「元に戻す（このファイルを元のソースに戻す）」ボタン（実際の処理は親に `onReset` で依頼する）
  - [ ] エディタのルート要素に `data-testid="code-editor"` を付ける（E2E で使う）
- [ ] 画面共有で見やすいフォントサイズ・行番号表示

## テストチェックリスト

- [ ] 入力すると間隔を置いて `onChange` が最新のテキストで 1 回呼ばれる（偽タイマー）
- [ ] JS ファイルでは確定操作まで `onChange` が呼ばれない
- [ ] `value` を外から変えるとエディタの内容が変わり、`onChange` は呼ばれない
- [ ] `highlight` を渡すと該当範囲に強調用のクラスが付く
- [ ] 拡張子ごとに言語が切り替わる
- [ ] バイナリファイルでエディタが開かない
